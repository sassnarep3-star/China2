# Independent critical-claim review

Scope: narrow review of consequential claims and one dated, partial cost illustration, not a certification of all repository content. Sources and limitations are visible alongside each finding in `index.html`. Rebuild with `python3 review-820042b6/build.py`.

The bank's indicative board prices and the personal electronic-banking tariff were read on 2026-11-11. The board is live; no guarantee that later viewers see the same price. The sender-fee formula assumes the commission is based on the RMB equivalent at the sell rate and uses the listed non-HK/Macau/Taiwan cable fee; this has not been confirmed for a customer's transaction. Actual tax, downstream fees and eligibility are not established.
