# Source Registry

Every fact published in this repository must trace to a row below. `Status` column:

| Status | Meaning |
|---|---|
| **Official** | Text was read on the official government / regulator site itself. |
| **Official (index only)** | Official site confirms the document *exists* (catalogue / law index) but the full text was not read. |
| **Secondary** | Reputable professional firm / secondary source. Not official. Any table row using only a secondary source must be flagged on the Flagged for Review page. |

Last verified: 2026-11-07.

## Verification method

1. Each value in a published table was read directly from the text of the official source in the row's Source column.
2. Where the official text could not be retrieved (network limits, paywall, Chinese-only PDF), the cell is left **blank** and the row is listed on the Flagged for Review page.
3. No value was inferred, estimated, or back-filled from memory.
4. Links were checked to resolve; the check date is 2026-11-07.
