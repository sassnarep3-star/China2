# China money research guide

A static, source-linked dashboard on lawful routes, costs and reporting considerations for moving money from China to the United States. This is educational research, not tax or legal advice. No account-specific conclusion or quote is possible without the source, amount and tax history.

## Site

GitHub Pages: https://sassnarep3-star.github.io/China2/ . Pages are generated from `build.py`; run `python3 build.py` after editing. No dependencies or server are required. Open `index.html` locally. Source links are primary government sources; older rules and applicability are explicitly flagged. `COORDINATION.md` records work and outstanding items.

## Checks

Run `python3 build.py` and `python3 test_site.py`. The tests check local links, source links on each table row, and generated files; they do not prove legal applicability or remote-site availability.
