EXECUTIVE SUMMARY

Start with the source of the money.
Not a workaround.

For documented, lawful China employment income, the first route to assess is an authorized bank conversion and outward remittance. Compare Wise only if its salary/tax-record criteria fit; compare HSBC Global Transfer only if account eligibility fits.

BOTTOM LINE · ANALYSIS

A restriction is not a tax.

Do not accept an unexplained “conversion penalty” as a single tax rate. Separate unpaid source tax, FX spread, wire costs, currency gains and any historical reporting penalties.
