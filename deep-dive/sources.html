Verification method

  1. Each value in a published table was read directly from the text of the official source in that row's Source column.
  2. Where the official text could not be retrieved, the cell is left blank and the row is listed on the Flagged for Review page.
  3. No value was inferred, estimated, or back-filled from memory.
  4. Links were checked to resolve on 2026-11-07.
  5. Arithmetic shown (for example the 32.5% dividend leakage) is a calculation from the cited rates, not a claim sourced from any single document.
